# Tiny Todo

A dead-simple to-do list. Add, check off, delete.

```bash
npm install
npm run dev
```

To-dos are saved in your browser's localStorage.

## Demo repo for PR Wrangler

This repo is the demo for [**PR Wrangler**](https://github.com/dhanush014/pr-wrangler), an AI review queue built as a LangChain Managed Deep Agent. The 15 open pull requests each hide a planted problem (a bug, a risky dependency, a collision with another PR). The labels, review briefs, "Start here" comments and the pinned **🤠 Review Queue** issue were all written by PR Wrangler.
